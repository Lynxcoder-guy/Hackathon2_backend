WHAT THIS BACKEND DOES
----------------------

1. Authentication
   - User registration
   - User login
   - Simple login
   - Admin registration
   - Admin login
   - Password hashing and verification
   - Upgrade of legacy plaintext passwords to hashed passwords
   - User, simple-user, and admin database management through a terminal tool

2. Pre-checkup workflow
   - Accepts a user token
   - Reads that user's health logs
   - Looks up the user name
   - Sends the logs to the Gobbie AI service
   - Generates and returns a summarized pre-checkup report
   - Includes offline and prompt testing utilities

3. Weekly health logs
   - Accepts health-log text
   - Stores the creation date
   - Associates the log with a user token

4. Post-checkup workflow
   - Saves original doctor advice
   - Saves a simplified-advice field
   - Stores the last checkup date
   - Provides an endpoint for retrieving actionable plans
   > Create the actionable plan
   > Create the simplified advice

MAIN API FEATURES
-----------------
The FastAPI application in main.py includes CORS configuration and these routers:

Authentication:
- POST /register-admin
- POST /check-user
- POST /simple-login
- POST /admin-register
- POST /admin-login

Pre-checkup:
- POST /pre-checkup

Weekly condition logs:
- POST /submit-health-log

Post-checkup:
- POST /post-checkup
- POST /actionable-plan

The root endpoint is:
- GET /
